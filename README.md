## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅳ 反思篇 · 第14章 新闻传播中的AI伦理**（教材 Tier 2 实验工具）。教材命名："沉默的螺旋互动论坛模拟器"。

**学习目标**：通过调节"恐惧孤立、点踩力度、媒体偏置、死硬派比例"等参数重现异见被淹没的过程，理解"私下观点分布≠可见舆论气候"的螺旋机制。

拖动「A 占比」会立刻改写智能体的私下立场，私下表与智能体人数一致。不拖这个滑杆时，私下分布在运行过程中保持不变，可见舆论仍会偏离。

**核心术语**：沉默的螺旋（Spiral of Silence）、意见气候（Climate of Opinion）、对孤立的恐惧（Fear of Isolation）、多智能体模拟（Agent-Based Modeling, ABM）

**适合对象**：新闻传播专业学生 / 媒介素养学习者 / 传播学研究者

**课前准备**：建议先读教材中诺依曼"沉默的螺旋"一节；工具打开即用、离线可用，全部模拟在本地浏览器完成。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师用默认参数点击"运行"，带学生盯住两个数字：私下分布几乎不动，可见舆论却逐渐倒向一边、"沉默%"持续攀升——抛出问题"为什么没有人改变观点，广场上却只剩一种声音"，引出对孤立的恐惧与意见气候感知。
2. **上手实操**（20 分钟）：学生按任务单完成 4 组对照实验：① 基准组：默认参数运行，记录可见/私下分布与沉默率；② 把"恐惧孤立"从 70% 降到 20%，观察螺旋是否还形成；③ 逐步调高"死硬派"比例，找出让异见不被清零的最低数值；④ 用"媒体偏置"滑杆制造一边倒的舆论气候，再用"+A帖/+B帖"手动干预，记录能否扭转 → 每组截图保存参数与结果。
3. **小组讨论**（8 分钟）：模拟显示少数"死硬派"就能撑住异见空间——在真实社交媒体上他们对应谁？平台按热度排序的可见度机制是应被矫正的"偏见"，还是难以避免的产品逻辑？当公共议题被螺旋压制时，谁应负责？
4. **总结**（4 分钟）：沉默的螺旋的核心不是"人们改变观点"，而是"人们改变是否发声"——可见度机制决定了意见气候的样貌。

**课后作业**：完成"三参数敏感性实验报告"：固定其余参数、每次只移动一个滑杆，用 3 组数据说明哪个参数对螺旋形成影响最大，并用教材理论解释原因。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

## 💻 本地开发

不要用 `file://` 双击打开。Service Worker 和 `../shared/` 都需要 HTTP。

```bash
npx serve .
# 或
python -m http.server
```

然后打开 `http://localhost:3000` 或 `http://localhost:8000`。地址栏加 `?seed=42` 可复现同一种子下的仿真。测试只依赖开发依赖 jsdom：`npm install` 后执行 `npm test`。
