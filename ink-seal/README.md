# 墨色标本

新闻实验工具的一版配色，用 P37 的版面当样子。这不是仿真，滑杆和「单步」只移动示意数字。

用浏览器打开 `index.html`。

## 上一版为什么像生成的

羊皮纸、朱砂、铜绿、暗金是一套配齐的暖色。纸、卡片、字和线都染在同一条棕色上，朱砂又铺满滑杆、按钮、链接和曲线。颜色在做全部的分层，所以看起来像一套主题，不像一页印好的纸。

## 这一版

界面只有纸和墨。朱砂只盖在「运行」上。

| 角色 | 色值 | 用在 |
| --- | --- | --- |
| 纸 | `#f6f3ec` | 整页。栏目不再另铺一块更亮的纸 |
| 墨 | `#1a1612` | 标题、正文、线、滑杆、曲线、次要操作 |
| 次墨 | `#5c564e` | 说明、轴和已经沉下去的帖 |
| 印 | `#9d2c24` | 只有「运行」 |

私下、可见、发帖靠实线、虚线和细线区分，不用红、绿、金。圆角为 0。没有阴影、纸纹和高光。
